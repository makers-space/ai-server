COMPONENT: Input

A text field the user can type in. What is typed stays in the field: it is not sent anywhere.

Written as `<Input label="..." />`. It holds nothing.

| Attribute | Values | What it does on screen |
|---|---|---|
| label | text | Shown above the field. |
| placeholder | text | Greyed text inside the field while it is empty. |
| multiline | no value | Makes the field several lines tall. |
| rows | a number | How many lines tall a multiline field is. |
